# V0.8 几何接触诊断
正常使用保持默认解析式动画，只有受支撑后封面局部曲率修正进入默认几何。以下 URL 参数为开发诊断，不是正式编辑功能。

| 参数 | 功能 |
| --- | --- |
| meshCollision=1/2 | 稀疏/密集线段采样 |
| meshCollision=3 | 实际变形网格 BVH 表面接触 |
| meshCollision=4 | 有界候选修正与同姿态复检 |
| meshCollision=5 | 线性顶点轨迹扫掠 |
| meshCollision=6 | 实体包含及非邻接自碰撞采样 |
| meshCollision=7 | Worker 独立实体诊断 |

诊断结果写入 canvas-host 的对应 data 属性，可由 Playwright 记录。Worker 的 captureMs 为主线程快照耗时、elapsedMs 为 Worker 计算耗时、inputBytes 为顶点及索引数组字节数。单任务在途，超时5秒终止，重建、上下文丢失及销毁时取消。不能把 Worker 内部时间当成端到端延迟。

## 验收与边界
- 穿透计数是相交三角形对，不是独立事件；正常支撑按明确材料面及相向法线分类。
- 模式5只针对两个捕获姿态的线性插值，hit 可包含尚未分类的接触；uncertain 和预算耗尽不等于安全。
- 模式6/7以原索引排除相邻面；完整遍历指该组非邻接候选遍历完毕，不能证明相邻折叠、连续运动或全部实体体积无冲突。
- 包含检测依赖闭合拓扑与有限顶点样本；近表面点及射线分歧保留不确定状态。
- 模式4仅在检测姿态接受不恶化候选，跨帧保留和端点衰减不保证中间帧正确；不默认启用。
- 发布前使用真实浏览器专项、固定开合角及极端规格、同规格本地基线视觉证据；Stripe Press 原站不同素材与镜头仅作为参考，不是像素级比较。
