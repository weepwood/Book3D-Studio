# V0.9 真实纸张规格与翻页运动

## 物理尺寸与兼容

- 自动模式：纸面数 P 对应 ceil(P/2) 张纸，书芯毫米厚度为纸张数乘以实测单张厚度，总厚度为书芯加两块封面。纸张厚度范围 0.04–0.25 mm，实际页数 2–2000，奇数页最后一张纸的背面为空白。
- 手动模式：保留旧版 8–80 mm 用户总厚度及原边缘纹理密度，显示反推纸厚。旧 JSON/IndexedDB version=1 没有新字段时迁移为手动；新建空白项目默认 320 页、0.1 mm 自动厚度；旧演示/导入不改变外观。复制项目保留原模式。
- 自动模式不覆盖原手动厚度参数，切回手动恢复原数值。封面厚度仍独立；当前没有把书脊胶层、环衬额外纸张建模为独立实体，不应假设克重可唯一推导纸厚。
- 页内容图片仍最多 40 张及既有编码总量限制，逻辑纸面可以超过素材数量，剩余使用演示内容；高页数用数值和滑块导航，避免创建千个下拉项目。
- 厚度变化在原模型内调整前后封面位置、装订根部、书脊及聚合书芯，重算依赖厚度的曲面缓存；宽、高、封面板厚、圆角、内缩、书脊结构仍按原逻辑重建。页数减少导致原活动页越界时取消非法运动、夹紧索引。

## 运动与渲染

- 统一运动时钟 120 Hz，单显示帧最多补偿六个子步（50 ms）；超出时间不追赶，避免暂停恢复直接跨过可见轨迹。渲染仍由 requestAnimationFrame 驱动。
- 单页、自动成组、手动释放共用速度连续、加速度有界的归一化进度积分器，快速成组只改变速度预算。拖拽使用临界阻尼目标跟踪，重抓从可见进度接续，释放保留速度；手动单叶释放使用同一积分器、0.65 倍响应时标。物理端点是硬边界。参考站观察用于既有模型，新的积分器是独立稳定性适配，不声称原版数值完全一致。
- 厚块自动进度连续起止，取消/释放复用统一积分器，保留实际可见交接叶与落地四帧门禁。活动纸张间距随薄纸实际厚度缩放，自动模式纸边纹理密度按真实层数更新；现有曲面端点、GPU 纸页形变和碰撞架构继续复用。
- 24 项页纹理 LRU：共享相同内容和翻转的纹理；内容版本隔离、活跃材质保护、空闲预热前后纸面、上下文丢失/销毁取消预热并释放资源。容量按纹理项数限制，并非精确 GPU 字节上限；预热遇到未完成图片解码时可延迟到自然渲染。
- 厚块重复使用清距临时数组、预计算网格索引和交接叶索引，仅纸边 UV 密度变化时更新 UV；保留必要法线和边界计算。

## 验收与诊断

本机 Apple M4 Metal + Edge，1280×800，硬件 GPU。基线 da00463，候选同一真实拖页测试：
| 指标 | 基线 | 候选 |
| --- | ---: | ---: |
| 实际提交帧数（含开书） | 225 | 217 |
| 帧间隔 P95（ms） | 16.8 | 16.8 |
| CPU 帧耗时 P95（ms） | 3.9 | 2.3 |
| GPU timer query P95（ms） | 1.566 | 0.958 |
| 拖动输入至提交 P95（ms） | 1.0 | 1.3 |
| 候选帧间隔 P99（ms） | — | 33.3 |
| 候选 CPU P99（ms） | — | 8.0 |

一次采样不是严格统计显著性结论。帧间隔包含小于 500ms 的按需渲染空闲间隔；输入至提交不是屏幕光子延迟，GPU query 不等同于完整渲染管线延迟。高页数候选 2000 页、1000 张、100 mm 纸芯，左/右名义 25/75 mm，实际外缘约 25.000005/75.000001 mm，geometryRevision=1；24 项缓存、18 次命中、32 次缺失、8 次淘汰。真实 800/2000 页截图与 169 叶厚块导航通过。最终高页数混合帧间隔 P99 50.03ms，不能直接归为实际掉帧，需活动窗口独立采样。

复现同条件专项：
```sh
BOOK3D_CHROMIUM_EXECUTABLE='/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge' BOOK3D_HARDWARE_GPU=1 npm run test:browser -- browser-tests/physical-motion.spec.ts browser-tests/continuity.spec.ts browser-tests/geometry-performance.spec.ts
```

额外可复现 CDP 活动帧、逻辑运动、GC 和堆采样脚本：
```sh
BOOK3D_CHROMIUM_EXECUTABLE='/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge' BOOK3D_HARDWARE_GPU=1 node scripts/physical-motion-bench.mjs BASELINE_DIR CANDIDATE_DIR /tmp/book3d-bench.json 43827
```
两个目录必须各自安装依赖，脚本独立启动 Vite，不复用已有服务。GC 仅统计实际 trace 中的 MinorGC/MajorGC 完整事件，堆前后差异不是内存泄漏证明。

最终 120/120 单元测试、类型检查、生产构建及 6/6 M4 浏览器专项通过（44.5s）。另实测单叶0.04mm、宽幅总厚1.64mm，以及窄幅2000页、0.25mm纸张、总厚256mm的稳定展开有限几何与旧版导入；极端规格不等同于全姿态碰撞认证。

剩余：完整非线性连续碰撞检测、真实移动/Windows GPU、长时间内存压力、超大素材分页存储、实体胶层/环衬，以及自动规格极端宽厚比的全姿态视觉认证。不得将有限采样称为零穿模或参考站像素一致。

## 第二轮：诊断长尾、交接端点与字节预算

PR #27 的 d9008d5 已通过 quick/capture/matched/triangle-contact/workspace，browser 中 25 项通过，camera-experience 第4行缩放收敛断言超时，随后整个任务达到10分钟上限。根因之一是物理时间截断50ms被复用到相机；恢复相机独立100ms上限（内部仍120Hz子步），不放宽断言。相机软件渲染专项本机通过（19.2s）。fit 使用实际推导的物理厚度而不是手动厚度字段。将原26项浏览器测试分为 browser-motion/browser-ui 两组，各自保留原10分钟任务上限；保留 browser 聚合门禁，仅当两组都通过才成功。未删减测试，workspace 增加 handoff-budget。

### 直接定位 CPU 长尾
同候选源码、同M4 Edge硬件、同连续拖动/前后翻页脚本，仅切换 ?pick=1，顺序采样，非随机多轮。原先 DEV 自动候选扫描在普通开发模式每次稳定落页时可能同步执行大量射线；生产构建原已不执行该扫描，不能将本结果解释为生产环境普遍提速。改为仅 DEV 且显式 pick=1；三项需要候选点的现有测试显式启用，实际拾取功能未改变。perf 增加各阶段时间与24个慢帧记录，脚本另记录活动状态转换边界。

| --- | ---: | ---: |
| 最近300提交帧 CPU P99(ms) | 398.6 | 3.3 |
| 活动窗口帧间隔 P99(ms) | 16.8 | 16.8 |
| 活动状态转换边界最大 RAF 间隔(ms) | 1850 | 16.8 |

最慢诊断帧1865.8ms，其中拾取1863.5ms、渲染1.3ms；关闭诊断后仍记录一次初始渲染86.2ms（渲染阶段85.6ms），未完全消除冷启动长尾。活动边界样本22/21，不等于真实屏幕显示延迟；GC频次受总耗时和运行环境影响。生产启动材质编译/上传需独立诊断。

### 真实端点与纹理预算
单叶落页在提交阅读索引前保留一次完整终点渲染；?handoff=1 采集15个一致材质坐标在活动CPU代理和切换后静止面的世界坐标，默认规格前后四次交接最大误差1.11e-14mm（浮点误差），新增0.01mm门禁。此非 GPU 像素对比，不覆盖所有厚块、多页中间轨迹及法线连续性。24项缓存同时限制192MiB保守估算（最多三张RGBA Canvas及一份带mipmap GPU副本）；纹理上限655360像素，普通比例保留原分辨率，极端宽高比按比例缩小实际栅格并保持逻辑排版。隐藏活动材质改用共享1像素占位并解除原纹理引用，LRU不回收使用中纹理。2000页测试19项、197916160字节（约188.75MiB）、14次淘汰、仍在预算内。该数值不含驱动额外开销、异步解码瞬态或其他几何显存。

本机122/122单测、类型、生产构建通过；14项真实M4硬件浏览器回归通过（约1.2min），包含原 reader/viewport、高页数与新增端点测试。独立软件GPU相机专项通过。原始采样：docs/benchmarks/v0.9-handoff-budget-m4.json。新门禁和最终全量远程CI需核对，仍不提前合并或发布。
