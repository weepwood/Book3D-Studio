# Book3D Studio

独立 Web 3D 书籍设计工作台，参考 Stripe Press 的交互设计思路，使用自有程序化几何及生成纹理，不复制其专有模型或素材。

## V0.2
- 五节骨骼蒙皮封面、连续权重与可调柔性；刚性模式可将柔性设为 0
- 前后分组书芯、开合联动、封面厚度、圆角、书芯内缩和方背/圆背
- 真实物体射线点击，旧版 JSON 自动填充新字段

## V0.1
- Three.js WebGL 实时渲染、环境光、阴影、旋转缩放
- 可调书籍尺寸、书脊、书页边缘、刚性封面开合
- 布面、哑光、光面，内置文字排版及自定义封面
- 点击、悬停倾斜和自由旋转模式
- JSON 导入导出、PNG 截图、本地自动保存
- 独立 TypeScript runtime，不依赖 React

## 本地开发

Node.js 22:
```sh
npm install
npm run dev
npm test
npm run build
```

GitHub Pages：在 Settings → Pages → Build and deployment 中选择 GitHub Actions，然后运行 Deploy Pages 工作流。
