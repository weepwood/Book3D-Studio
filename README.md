# Book3D Studio

独立 Web 3D 书籍设计工作台，参考 Stripe Press 的交互设计思路，使用自有程序化几何及生成纹理，不复制其专有模型或素材。

## V0.4.1 · 翻页物理与细节
- 帧率无关阻尼翻页、释放速度预测、拖拽取消、悬停页边拾取与页角局部形变
- 活动页从书芯中分离，落点与静止纸面匹配，背面透印纹理合成
- 专项几何与状态测试；仍为解析式近似，非完整纸张碰撞/布料物理

## V0.4 · 逐页阅读优先
- 180° 展开，独立双面页纹理、实时曲面网格、书芯厚度转移与页码
- 左右页点击、键盘、触摸拖动跟随、松手完成或回弹；可调曲率和时长
- 原创演示内页及最多 40 张本地图片的导入、排序、删除；配置兼容旧项目
- 当前为解析式曲面，不是完整软体物理；暂未支持 PDF、透印和高精度页角碰撞

## V0.3
- 可折叠、拖动调整面板；数字输入、视角切换、撤销重做（40 步）
- IndexedDB 多项目与本地素材库，读取旧 localStorage 项目，JSON 仍为自包含格式
- 封面、封底、书脊分别配置图像及裁剪位置，文字编辑
- 材质更新与几何重建分离；几何尺寸变化仍重建模型
- 暂不支持跨标签页编辑冲突合并、自由图层排版与真正正交投影

## V0.2
- 五节骨骼蒙皮封面、连续权重与可调柔性；刚性模式可将柔性设为 0
- 前后分组书芯、开合联动、封面厚度、圆角、书芯内缩和方背/圆背
- 真实物体射线点击，旧版 JSON 自动填充新字段

## V0.1
- Three.js WebGL 实时渲染、环境光、阴影、旋转缩放
- 可调书籍尺寸、书脊、书页边缘、刚性封面开合
- 布面、哑光、光面，内置文字排版及自定义封面
- 点击、悬停倾斜和自由旋转模式
- JSON 导入导出、PNG 截图、本地自动保存
- 独立 TypeScript runtime，不依赖 React

## 本地开发

Node.js 22:
```sh
npm install
npm run dev
npm test
npm run build
```

GitHub Pages：在 Settings → Pages → Build and deployment 中选择 GitHub Actions，然后运行 Deploy Pages 工作流。
